# LUMI Store — Премиальный интернет-магазин электроники

LUMI Store — современный e-commerce веб-сервис с адаптивным космическим неоновым дизайном (глубокий тёмный фон, лавандово-фиолетовые свечения, Bento Grid промо-блоки).

## 🚀 Стек технологий

- **Фреймворк:** Next.js (App Router, React 19 / TypeScript)
- **Стилизация:** Модульный CSS / Vanilla CSS дизайн-система с дизайн-токенами
- **Иконки:** Lucide React
- **База данных (в планах):** Neon Serverless PostgreSQL + Prisma ORM
- **Платёжный шлюз (в планах):** YooKassa
- **Мобильные клиенты (в планах):** Telegram Mini App & React Native

## 📦 Быстрый старт

1. Установка зависимостей:
```bash
npm install
```

2. Запуск локального сервера разработки:
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📁 Структура проекта

- `src/app/` — Маршруты и страницы приложения (Next.js App Router)
- `src/components/` — UI библиотека и общие компоненты
- `src/data/` — Мок-данные для витрины и каталога
- `src/styles/` — Дизайн-токены, переменные и глобальные стили
- `src/types/` — Описания типов TypeScript
